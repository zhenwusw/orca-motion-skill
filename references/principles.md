# MG 动画原则

这类动画（苹果发布会的产品介绍、Remotion 做的产品概念片）能做得好看，前提是**产品本身符合设计规范**：
界面由少数几种元素、一套网格、一个强调色组成。所以可以把它抽象成更少的几种图形，
抽象之后，缩放、重排、变形都不会乱。

## 1. 抽象：产品里的东西 → 最多 4 种图形

先列产品界面里有什么，再给每样东西找一个图形，**只保留讲故事需要的信息**。

| 产品里 | 抽象成 | 例子（Clearing 日历） |
| --- | --- | --- |
| 很多个同类的东西（天、订单、用户） | 格子 `m.grid` | 一年 365 天 → 7×53 的格子，深浅 = 忙碌程度 |
| 有起止时间的东西 | 横条 `m.agenda` | 一天的日程 → 时间轴上的块 |
| 一个结论、一个动作 | 卡片 `.mo-card` | 「Clear. 30 min kept for you」 |
| 一个数 | 数字 `m.count` | 2,184 events → 63.5 hours kept |
| 一条条记录（账单、消息、订单） | 列表行 `m.rows` | 九月的 12 笔扣款（Sieve 示例） |
| 随时间变化的量 | 折线 `m.line` + `m.draw` | 一年累计省下的钱（Sieve 示例） |

图形上的文字能省就省：格子里没有字，日程块只写标题和时间。

## 2. 主角：一个东西、一个颜色，贯穿全片

- 整段片子只有**一个主角**，用主题的强调色（`--accent`，`.mo-hot` `.mo-card` `.mo-rule` `.mo-dot`）。
- 其他所有东西都是白色半透明的背景信息，深浅表示数量，不用第二种颜色。
- 主角在每个场景里换形状，但**颜色不变**：扫描线（黄）→ 卡片（黄）→ 格子（黄）→ 拼出的字（黄）。
  观众靠这个颜色跟住故事。
- 主角第一次出现之前，画面里不能有强调色。

## 3. 同一个数据模型，不同的尺度

场景不是一页页不同的画面，而是**同一份数据在不同尺度下的样子**：
全年（格子）→ 一天（横条）→ 半小时（卡片）→ 全年（拼字）。

- 往细处走用「放大进元素内部」（orca-transition-skill 的 `zoom-into` in）：格子里面就是那一天。
- 往回走用 `zoom-into` out：那一天缩回格子里，这个格子已经变成了主角的颜色。
- 场景内部的小幅推近用 `m.camera`（比如推近到那个空档），不用切场景。

## 4. 一个场景只讲一件事

每个场景的时间线分三段：

| 段 | 做什么 | 时长 |
| --- | --- | --- |
| 建立 | 图形成片出现（`m.appear`），数字滚到位 | 1–2 秒 |
| 发生 | 主角出现或变化（一个动作） | 1–2 秒 |
| 停 | 什么都不动，让观众看清 | 0.3 秒以上 |

- **被转场推进来的场景，第 0 秒就是「建立」之后的画面**。转场拍到的是场景第 0 秒：
  如果图形要在场景里才出现，推进时只能看到空面板。这种场景不排建立段，图形直接画好，
  时间线从「发生」开始（比如 Clearing 的 day：日程一开始就在，场景直接走扫描线）。
  只有第一页、遮挡剪辑之后这类「从空画面开始」的场景才排建立段。
- 成片出现用波浪（`m.appear`，按离起点的距离错开），不要一个一个排。`span` 1.0–1.5 秒。
- 主角的动作要比建立段**慢、大、单独**：同一时间只有它在动。
- 数字滚动和图形出现同时进行，数字停下时图形也差不多到位。

## 5. 运动的质感

- 弹出用 `pop`（`back.out`，有一点过冲），落下用 `rise`，镜头用 `power3.inOut`。
- 高亮一个格子用 `m.heat`：变色的同时弹一下，比单纯变色醒目。
- 拼字按列从左往右点亮，每列 0.03–0.04 秒，像在「写」。
- **景深分层**：主角清晰，背景信息虚掉（`m.blur`）。只交代上下文的东西（一周里旁边的两天）第 0 秒就虚；
  主角动作时（镜头推近、收拢），把周围的东西在同一段时间里虚掉，和 `m.dim` 一起用。虚化 2–5px，不要糊到认不出形状。
- 每个场景都铺 `m.backdrop()`：纯色底显得平，一团柔光让画面有纵深。
- 文字换内容用 `m.swapText`（出去再进来），不要原地跳字。

## 自检标准

录制完，按正常速度看一遍，再抽帧：

1. 能不能用一句话说出每个场景里「主角怎么了」。说不出来就是这个场景讲了不止一件事。
2. 强调色是不是只出现在主角身上。
3. 成片出现是不是一波一波的，而不是整片同时出现或一个一个蹦。
4. 主角动作的时候，画面里是否只有它在动。
5. 每个场景结尾有没有停住的时间。
6. 场景之间的转场：前一个场景的主角，是不是在下一个场景里找得到。
